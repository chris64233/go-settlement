# go-settlement

开发环境：Go 1.23.0。

运行测试：

    go test ./...

## 结算争议处理

包 `settlement` 实现结算后的资金争议处理，核心入口为 `Service`：

- `CreateSettlement` / `CompleteSettlement`：创建原结算并按原计划支付未冻结部分。
- `ApplyDispute`：受理争议，关联原结算、争议金额、原因、证据摘要与发起方。
- `Decide`：作出处理决定（驳回 / 退回付款方 / 继续支付收款方），记录决定人、理由与采用的证据版本。
- `GetSettlementView`：一次查询原结算、被冻结金额、争议证据、决定与后续调整。

### 原记录与调整记录的关系

原结算记录（`Settlement`）的金额、收付双方创建后不可修改，争议永远不会回写原记录：

- 结算尚未发送时，受理争议只增加 `FrozenAmount` 冻结对应金额，未争议部分仍按原计划支付。
- 结算已完成时，争议只登记为待处理，成功状态（`COMPLETED`）不会回退为处理中。
- 处理决定执行时，一次性写入不可修改的决定记录（`Decision`）和独立的资金调整记录
  （`Adjustment`，驳回除外）。退回付款方或继续支付收款方的资金流转全部通过调整记录
  独立核算，与原结算记录关联但不修改它。

### 关键规则

- 争议号为幂等键：内容一致重复申请返回原结果；金额或原结算变化返回冲突。
- 同一结算的累计争议金额不得超过原结算金额。
- 同一争议最多成功执行一次决定；执行失败时原结算与冻结金额保持不变，可继续处理。
