# go-settlement

银行转账结算与退汇处理模块（Go 1.23.0，包名 `settlement`）。

## 功能

- **转账指令**：`CreateTransfer` 创建指令（PENDING），`ConfirmTransferSuccess` 确认成功并保存银行成功回执；成功结果不可更改、不可删除，重复确认同回执幂等。
- **账户余额**：`OpenAccount` / `Deposit` / `Freeze` / `Withdraw` 维护业务方可用与冻结余额。
- **退汇受理**：`ConfirmReturn` 关联原银行指令，保存银行退汇号、退回金额、币种、原因、回执时间。仅当原指令已成功且币种匹配时受理；一笔转账可分多次退回，累计退回金额不得超过原转账金额。每次确认增加业务方可用余额并生成独立资金台账（`RETURN_CREDIT`），不回改原转账状态、不删除原成功回执。
- **幂等与冲突**：银行退汇号全局唯一。相同退汇号且原指令、金额、币种一致时返回首次结果；任一关键信息不同返回 `ErrReturnConflict`（`*ConflictError`）。
- **冲正**：`ReverseReturn` 对错误退汇独立冲正扣回，生成 `REVERSAL_DEBIT` 台账，累计冲正不得超过该退汇已入账金额；余额不足时失败且不产生台账。
- **并发原子性**：退汇确认、冻结、提现共用同一互斥锁，余额变化与台账在同一临界区生效，任何失败不会只完成一边；并发退汇不会超额入账。
- **查询**：`GetTransferView` 展示原转账、全部退汇、冲正关联、可用余额与当前可退剩余金额；`Ledger` 返回业务方全部资金台账。
