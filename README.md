# go-settlement

开发环境：Go 1.23.0。

运行测试：

    go test ./...

## 结算争议处理

`settlement.go` 提供结算后的资金争议处理能力，核心入口为 `Store`：

- `FileDispute` 受理争议：关联原结算、争议金额、原因、证据摘要与发起方。
  相同争议号且内容一致时幂等返回原结果；金额或原结算变化时返回冲突。
  同一结算的累计争议金额不得超过原结算金额。
- `Decide` 做出处理决定：驳回、退回付款方或继续支付收款方，
  并记录决定人、理由与采用的证据版本。决定与资金调整一次性写入，
  同一争议并发处理最多一个成功；写入失败时原结算与冻结金额保持不变，可重试。
- `GetSettlementView` 查询视图：同时展示原结算、被冻结金额、争议证据、
  决定记录与后续调整。

### 原记录与调整记录的关系

原结算记录（`Settlement`）一旦创建，其金额与状态流转不会被争议修改或回退：

- 结算尚未完成时，受理争议只增加 `FrozenAmount` 冻结额，未争议部分仍按原计划继续；
- 结算已完成时，争议不触碰原结算（成功状态不会改回处理中），只形成待处理调整；
- 决定执行后产生独立的资金调整记录（`Adjustment`，正数支付收款方、负数退回付款方）
  与不可修改的决定记录（`Decision`）。原结算的历史始终完整，所有资金变化
  都通过调整记录体现，二者通过结算号与争议号关联。
