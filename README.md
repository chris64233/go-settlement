# go-settlement

开发环境：Go 1.23.0。

运行测试：

    go test ./...

## 结算转账银行拒绝修复

提供结算转账创建、银行回执登记与拒绝后修复能力。核心代码位于
`types.go`（领域模型）与 `service.go`（业务逻辑），测试见 `service_test.go`。

### 功能

- **转账创建**：`CreateTransfer` 创建银行指令并同时占用资金预留，按
  `RequestNo` 幂等，同号不同内容返回冲突。
- **回执登记**：`RegisterReceipt` 登记银行成功/拒绝回执，回执完整保留、
  按 `ReceiptNo` 幂等。拒绝回执使指令进入 `REJECTED`。
- **修复申请**：`CreateRepair` 仅允许已收到明确拒绝回执且尚未成功的指令。
  申请固定原指令、拒绝原因、原收款信息摘要、新收款信息与原指令版本，
  不修改旧指令；按 `RepairNo` 幂等，同号不同内容返回冲突。
- **修复确认**：`ConfirmRepair` 生成关联的新银行指令，金额、币种、资金
  归属与原指令一致，仅收款信息变更；原资金预留原子迁移到新指令（不先
  释放再占用）。生成新指令、迁移预留、记录修复关系在同一把锁内一起
  成功，失败不留中间状态。`CancelRepair` 可取消待确认的修复。
- **并发竞争**：原指令成功回执、修复确认与取消同时到达时，只有一条指令
  获得最终成功：原指令先成功则修复作废（`OBSOLETE`）；新指令先生成后
  收到迟到的成功回执，则标记人工处理，不重复记账。
- **查询**：`GetInstruction` 返回原指令、全部修复版本、银行回执、资金
  预留去向与需要人工处理的异常；`Exceptions` 返回全部人工处理异常。
